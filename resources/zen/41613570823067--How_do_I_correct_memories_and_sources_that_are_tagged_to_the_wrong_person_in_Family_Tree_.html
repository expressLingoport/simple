You can fix inaccurate tags on a memory (a photo, story, document, or audio file) in Family Tree.

You can fix incorrect tags in memories and sources.
 

Steps (website)

Memory items
 

  1. Sign in to FamilySearch
  2. Navigate to the memory item with the incorrect tag.
  3. Click the item.

  4. To the right of the image, find the View All Tags box. The default setting will show you all tags in the memory. Click the Down Arrow icon to view tags by person, or by tree.

  5. Your option varies depending on whether you or another person contributed the memory item and tagged it.
    1. If contributed by you:
      1. Click the Gear Icon next to the person's name.
      2. Click Delete on the pop-up.
    2. If contributed by another person:
      1. Click Gear Icon next to the person's name.
      2. Click the Paperclip Icon on the pop-up.
      3. Enter a reason statement.
      4. Click Detach.
  6. To create a tag for the correct person, click the image or the Tag People button in a written memory.
  7. Drag the tag box to the correct position. Use the green dot to resize the tag.
  8. In the box next to the tag, enter the name of the correct ancestor. Click the name and then click Tag Selected.

Sources
 

  1. Sign in to FamilySearch.
  2. In Family Tree, navigate to the person with the incorrectly tagged source.
  3. Near the top, click the Sources tab.
  4. Click the source that was tagged to the wrong person.
  5. Copy the URL if the source is from the Internet.
  6. Click Detach. Enter your reason and click Detach.
  7. Navigate to the person to whom the source belongs.
  8. Click Sources.
  9. Click Add Source. Click the appropriate option:
    1. Add New Source allows you to add using the URL.
    2. Add New Memory Source allows you to add from your Memories Gallery.
    3. Attach from Source Box allows you to add from your Source Box.
  10. Enter the appropriate information from the screens that come up.
  11. Click Save or Attach.

Steps (Mobile app)

Memories
 

  1. Open the Family Tree Memories app.
  2. Find and tap the image with an incorrect tag.
  3. Tap the icon that looks like a person to see current tags. (If you do not see the icon, tap in the memory item.)
  4. Tap on the icon shaped like a person.
  5. Tap inside the circle or square on the picture that shows the incorrect tag.
  6. To the top left of the shape, tap X. On Android devices, the tag disappears. On Apple iOS, tap Delete.
  7. Tap in the image. Use the edge of the tag to move and size it.
  8. Tap Add Name.
  9. Enter the name, or find by ID.
  10. Tap the name in the list.
  11. Tap Done.

In the Family Tree mobile app, navigate to a person page. Tap the Memories tab. Tap the memory with an incorrect tag. Continue with the steps for the Memories app.

Sources
 

  1. Open a person's profile in the Family Tree mobile app.
  2. Tap the Sources tab.
  3. Tap the source that you want to detach.
  4. In the upper right, tap the 3 dots icon.
  5. Tap Detach.
  6. Enter a reason and tap Detach.
