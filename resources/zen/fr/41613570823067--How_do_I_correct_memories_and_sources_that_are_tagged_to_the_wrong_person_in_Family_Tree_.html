<zd-summary-block>

Vous pouvez corriger les balises inexactes sur une mémoire (une photo, une histoire, un document ou un fichier audio) dans l'Arbre Généalogique.

</zd-summary-block>

Vous pouvez corriger les balises incorrectes dans les mémoires et les sources.
 

Étapes (site internet)

Éléments de mémoire
 

  1. Ouvrir une session sur le site de FamilySearch
  2. Naviguez vers l'élément de mémoire avec l'étiquette incorrecte.
  3. Cliquez sur l'élément.

  4. À droite de l'image, trouvez la boîte Voir tous les tags . Le paramètre par défaut vous montrera toutes les balises dans la mémoire. Cliquez sur l'icône Flèche vers le bas pour afficher les balises par personne ou par arbre.

  5. Votre option varie en fonction de si vous ou une autre personne avez contribué à l'élément de mémoire et l'avez étiqueté.
    1. Si contribué par vous :
      1. Cliquez sur l' icône d'engrenage à côté du nom de la personne.
      2. Cliquez Supprimer dans la fenêtre contextuelle.
    2. Si contribué par une autre personne :
      1. Cliquez sur l'icône d'engrenage à côté du nom de la personne.
      2. Cliquez  sur l' icône du trombone dans le pop-up.
      3. Entrez une déclaration de raison.
      4. Cliquez sur Détacher.
  6. Pour créer une étiquette pour la bonne personne, cliquez sur l'image ou sur le Taguer des personnes bouton dans une mémoire écrite.
  7. Faites glisser la boîte de balise à la bonne position. Utilisez le point vert pour redimensionner l'étiquette.
  8. Dans la case à côté de l'étiquette, entrez le nom de l'ancêtre correct. Cliquez sur le nom puis cliquez sur Tag Sélectionné.

Sources
 

  1. Saisissez vos identifiants du site de FamilySearch.
  2. Dans l'Arbre généalogique, naviguez vers la personne avec la source mal étiquetée.
  3. Près du haut, cliquez sur l'onglet Sources .
  4. Cliquez sur la source qui a été étiquetée à la mauvaise personne.
  5. Copiez l'URL si la source provient d'Internet.
  6. Cliquez Détacher. Entrez votre raison et cliquez sur Détacher.
  7. Naviguez vers la personne à qui appartient la source.
  8. Cliquez sur Sources.
  9. Cliquez Ajouter une source. Cliquez sur l'option appropriée :
    1. Ajouter une nouvelle source vous permet d'ajouter en utilisant l'URL.
    2. Ajouter une nouvelle source de mémoire vous permet d'ajouter depuis votre galerie de souvenirs.
    3. Attacher depuis la boîte source vous permet d'ajouter depuis votre boîte source.
  10. Entrez les informations appropriées à partir des écrans qui apparaissent.
  11. Cliquez Enregistrer ou Joindre.

Étapes (Application mobile)

Souvenirs
 

  1. Ouvrez l'application Family Tree Memories.
  2. Trouvez et appuyez sur l'image avec une étiquette incorrecte.
  3. Appuyez sur l'icône qui ressemble à une personne pour voir les étiquettes actuelles. (Si vous ne voyez pas l'icône, appuyez sur l'élément de mémoire.)
  4. Appuyez sur l'icône en forme de personne.
  5. Touchez à l'intérieur du cercle ou du carré sur l'image qui montre l'étiquette incorrecte.
  6. En haut à gauche de la forme, appuyez sur X. Sur les appareils Android, la balise disparaît. Sur Apple iOS, appuyez sur Supprimer.
  7. Appuyez sur l'image. Utilisez le bord de l'étiquette pour le déplacer et le redimensionner.
  8. Appuyez sur Ajouter un nom.
  9. Entrez le nom, ou trouvez par ID.
  10. Appuyez sur le nom dans la liste.
  11. Appuyez sur Fait.

Dans l'application mobile Family Tree, accédez à une page de personne. Appuyez sur l'onglet Souvenirs . Touchez la mémoire avec une étiquette incorrecte. Continuez avec les étapes pour l'application Memories.

Sources
 

  1. Ouvrez le profil d'une personne dans l'application mobile Arbre Généalogique.
  2. Appuyez sur le Sources onglet.
  3. Appuyez sur la source que vous souhaitez détacher.
  4. Dans le coin supérieur droit, appuyez sur l' icône des 3 points.
  5. Appuyez sur Détacher.
  6. Entrez une raison et appuyez sur Détacher.
